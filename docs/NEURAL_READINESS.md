# Neural Readiness — Alertness Probe

Daily Neural Check uses a roughly 60-second **Alertness Probe｜警觉性反应** to observe response speed, stability, and early responses relative to a personal short-form baseline. The retained 3-minute **Calibration PVT｜警觉性校准测试** provides more trials for sustained-alertness trends.

The protocols are separate: `daily_short` uses `alertness_probe_v1`, `weekly_calibration` uses `pvt_calibration_3min_v1`, and historical `pvt_b_v1` data is retained as `legacy_3min`. Results are for personal longitudinal observation only; neither protocol diagnoses medical conditions, central-nervous-system fatigue, or driving suitability.
